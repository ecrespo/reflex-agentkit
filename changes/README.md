# Changes

Proposals that change the observable behavior or the public API of a released
reflex-agentkit (CLAUDE.md, spec-anchored process). Each change lives in
`changes/<yyyy-mm>-<slug>/` with `proposal.md`, `delta-spec.md` and `tasks.md`. Once the
maintainer approves it and it ships, the delta is folded into `specs/` in the same PR and
the folder moves to `changes/_archive/`.
